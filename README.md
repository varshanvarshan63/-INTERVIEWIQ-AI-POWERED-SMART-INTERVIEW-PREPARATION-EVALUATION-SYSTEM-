# InterviewIQ – AI-Powered Smart Interview Preparation & Evaluation System

InterviewIQ is an AI-powered web application designed to help students, fresh graduates, and job seekers prepare for interviews through intelligent mock interview sessions, resume analysis, personalized feedback, and performance evaluation.

The platform simulates real interview environments using Artificial Intelligence and Natural Language Processing (NLP), allowing users to improve their communication, technical knowledge, confidence, and interview performance before attending actual interviews.

# Overview

Job interviews are one of the biggest challenges for students and professionals. Traditional interview preparation relies on static question banks, online videos, and self-practice, which rarely provide personalized evaluation or real-time feedback.

InterviewIQ bridges this gap by providing an AI interviewer capable of:

- Conducting realistic mock interviews
- Generating role-specific questions
- Evaluating answers intelligently
- Analyzing resumes
- Tracking user performance
- Suggesting personalized improvements

The platform creates an interview experience similar to actual company interviews.

# Installation

Clone the repository

```bash
git clone https://github.com/yourusername/InterviewIQ.git
```

Navigate to the project

```bash
cd InterviewIQ
```

Install dependencies

```bash
npm install
```

Run frontend

```bash
npm run dev
```

Run backend

```bash
python app.py
```
